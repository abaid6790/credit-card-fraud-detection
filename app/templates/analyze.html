What are V1–V28?

V1–V28 are anonymized PCA (Principal Component Analysis) features. The original transaction details (merchant, location, card type, etc.) were mathematically transformed into these 28 numbers to protect customer privacy — so there's no real-world label like "merchant category" to read off them, and no "correct" value to guess. Most values fall roughly between -3 and +3; values far outside that range (e.g. -10, +8) tend to look more unusual to the model.

Time is seconds elapsed since the first transaction in the dataset (0 to ~172,792). Amount is the transaction amount in the dataset's currency units.

How to test this

Since V1–V28 have no intuitive values to type from scratch, the easiest way to test is to load a real transaction from your dataset and see what the model predicts — then optionally tweak a few numbers to see how the prediction changes.

You can also open your data/creditcard.csv in Excel/Sheets, copy any row's values, and paste them in one at a time — rows where Class = 1 are known fraud, Class = 0 are known legitimate.
