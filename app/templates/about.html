What this is

FraudGuard is a machine-learning-based fraud-risk detection system, built on the Kaggle "Credit Card Fraud Detection" dataset (anonymized European card transactions, 2013). It classifies transactions as legitimate or potentially fraudulent and produces a 0–100 risk score derived directly from the trained model's fraud probability.

What this is not

This is not a guaranteed fraud-detection system and is not certified for production banking use. A flagged transaction is not proof of fraud, and an unflagged transaction is not a guarantee of legitimacy.

Limitations

  • The dataset covers only two days of transactions from one processor in 2013.
  • Features V1–V28 are anonymized PCA components with no interpretable real-world meaning.
  • There is no merchant, device, geolocation, or customer-history data.
  • A production system would additionally need real-time streams, transaction velocity features, device fingerprinting, continuous retraining, drift monitoring, and human review.
